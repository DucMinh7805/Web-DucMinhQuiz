# Cấu trúc Sheet WEB

- `DM_Bao Mat`: mã của Sheet Mật khẩu, đăng nhập và quyền quản trị.
- `DM_Len De`: mã của Sheet Lên đề, gồm chuyên khoa, đề thi, hình ảnh và giá môn học.
- `DM_Tai Lieu`: toàn bộ mã gắn trực tiếp với Sheet Tài liệu riêng. Menu tài liệu, kết nối dữ liệu, đồng bộ web, tên, link, giá, ghi chú giá, tác giả, ảnh bìa và trạng thái đều nằm tại đây.

Sheet Lên đề chỉ hiển thị menu `📝 Lên đề DM|Quiz`; Sheet Tài liệu chỉ hiển thị menu `📚 Tài liệu DM|Quiz`.

`Question_Overrides` là bảng hệ thống ẩn dùng để lưu các chỉnh sửa câu hỏi đã được Admin duyệt. Không nhập dữ liệu trực tiếp và không xóa bảng này.
